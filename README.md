# NeuroCare 🧠

AI-powered mental health support platform focused on:
- Anxiety tracking
- Panic attack assistance
- Mood monitoring
- AI insights
- Mental wellness dashboard

## Tech Stack
- React + Vite
- Tailwind CSS
- Flask Backend
- TensorFlow.js (planned)
- OpenStreetMap + Leaflet

## Features
- User Authentication
- Mood Tracking
- AI Stress Analysis
- Panic Mode
- Nearby Hospitals
- AI Chat Support
